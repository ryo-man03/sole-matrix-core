# SOLE//MATRIX v1.1.1 — Live External Product URLs

Status: Draft on `fix/separate-entry-flows-and-url-qa`. This work does not create a `v1.1.1` tag or GitHub Release and does not modify the existing `v1.1.0` release.

## Summary

- Resolves external product references after the eight-question recommendation
- Verifies public HTTP/HTTPS, DNS safety, redirects, and current HTTP status before display
- Prefers verified direct Rakuten listing URLs and labels verified search URLs as fallbacks
- Shows domain, source, verification status, `verifiedAt`, and a non-guarantee note
- Supports a safe manual URL check without persisting the submitted URL
- Keeps unavailable or blocked URLs out of link buttons
- Separates `/`, `/login`, mode selection, eight-question diagnosis, and product judgment
- Shows the recommended model and safe reference links after the standalone diagnosis
- Adds PC 1440px and mobile 390px route screenshots

## Decision boundary

- Product URLs do not change the candidate or Core score.
- Product URLs do not change `budgetFit`.
- Product URLs do not change the Core or mode Decision.
- Link resolution failure does not remove or invalidate the recommendation.
- Search fallback is not represented as a direct product page.

## Security and persistence boundary

- The existing URL-analysis SSRF boundary is reused for schemes, credentials, ports, localhost, tunnel domains, DNS results, private/reserved addresses, and redirects.
- Verification uses bounded HEAD or minimal GET status checks; it does not scrape product contents.
- Tracking, affiliate, token-like query parameters, and fragments are removed before display.
- Generated, verified, and manual raw URLs are not persisted to user memory or the global feedback corpus.
- User-memory and corpus free text redact URL-like values.
- External links use `target="_blank"` with `rel="noopener noreferrer"`.

## Product boundary

- No price comparison or lowest-price claim
- No stock or size guarantee
- No inventory or purchase-location guarantee
- No all-provider shopping API integration
- No direct product URL guarantee for every recommendation
