# SOLE//MATRIX Core v1.0.0 — Release Notes

Status: release candidate on `feature/all-in-one-pc-backend-vision-ryo-mode`. Merge and v1.0.0 tag are not performed yet.

## Highlights

- All-in-one PC 3-column recommendation workspace
- Eight-question diagnosis mapped to a reproducible `PreferenceVector`
- Ryo Mode and Balanced Mode with separate evaluation perspectives
- Ryo seed v2 based on 41 owned pairs and 40 deduplicated wishlist candidates
- TypeScript-controlled Balanced Score, Ryo Score, and final Decision
- Structured Gemini explanation and visual feature extraction
- Safe sneaker URL metadata analysis with SSRF protection
- JPEG / PNG / WebP upload validation without persistent image storage
- Local user profile, diagnosis history, and feedback persistence
- Rakuten candidate normalization, readiness reporting, and safe fallback
- Backend route/service boundary and frontend API client
- Documentation, security notes, browser QA, and screenshot evidence

## Safety Boundaries

- Gemini never determines or changes recommendation scores or Decision
- `memory.md` is handled as untrusted user data, not as AI instructions
- Runtime user memory is gitignored; only `data/users/.gitkeep` is tracked
- URL analysis rejects unsafe schemes, credentials, non-standard ports, localhost, private/reserved IPs, and unsafe redirects
- Image analysis validates MIME type, magic bytes, size, and forbidden AI output fields
- API keys, request URLs, full queries, raw HTML, and raw provider responses are not logged or returned
- Rakuten HTTP 403 / 429 and invalid responses fall back to local candidates
