# Consent policy

Optional processing defaults to off. AI processing, search grounding, recommendation history, behavioral personalization, analytics, notifications, and external-provider lookup are separately recorded with policy version and timestamp. Core deterministic recommendations remain available when AI/search consent is absent.

Explicit product actions (purchase reports, fit feedback, wishlist changes, recommendation feedback, and user-requested market searches) may be stored when submitted by the authenticated owner. Behavior analytics (recommendation views and market-listing clicks) are stored only when the latest analytics consent is granted. Fit feedback updates the deterministic Fit Preference Profile only when the latest behavior-personalization consent is granted. No third-party tracker is used, and event persistence is not automatic model training.
